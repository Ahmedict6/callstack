Privacy Policy — Call Stack Uploader

Last updated: October 24, 2026

Call Stack Uploader is a private tool used only by the owner of the Call Stack YouTube channel. It is not offered to the public.

What data it accesses

With the owner's permission, through Google sign-in, the tool uses the YouTube Data API and YouTube Analytics API to upload and schedule videos, set thumbnails and captions, and read statistics for the owner's own channel.

How data is stored

The sign-in token and channel statistics are stored only on the owner's own computer. Nothing is sent to any other server.

Sharing

No data is sold, shared or transferred to anyone. The tool does not access any other user's data.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions.

Contact

Questions: open an issue at github.com/Ahmedict6/callstack.
